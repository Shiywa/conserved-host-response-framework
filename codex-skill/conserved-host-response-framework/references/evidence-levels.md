# Evidence levels

Classify each result before writing.

1. **Construction evidence**: contributes to membership and cannot serve as post-freeze validation.
2. **Independent infection validation**: tests unchanged membership and scoring in a distinct study family.
3. **Cross-system support**: tests direction or module recurrence across species, tissues, or models.
4. **Clinical association**: relates frozen scores to contemporaneous outcomes; not prediction by default.
5. **Cellular localization**: places activity in donor/patient pseudobulks; not cell-cell communication by default.
6. **Longitudinal association**: tests within-person change; not complete normalization or reversibility by default.
7. **Specificity context**: evaluates other diseases or pathogens; positive effects limit specificity claims.
8. **Mechanistic evidence**: requires perturbation or a design supporting causal identification.

Treat multiple datasets from one study family as related evidence fields, not independent cohorts. Report endpoint heterogeneity instead of forcing pooled interpretation.
