# Claim guardrails

## Supported when directly demonstrated

- frozen, versioned gene/module/scoring definition;
- post-freeze induction or association;
- directionally conserved program-level response;
- context-dependent module reweighting;
- donor/patient-level cellular localization;
- dataset-limited longitudinal change;
- reusable configuration-driven implementation.

## Require additional evidence

- diagnostic or prognostic biomarker;
- prospective severity predictor;
- absolute cross-platform response scale;
- universal cross-disease method;
- mechanistic driver or causal pathway;
- cross-compartment signaling;
- complete recovery or reversibility;
- pathogen specificity;
- superiority to previous signatures.

Use “supports,” “is associated with,” “is consistent with,” or “provides a framework for” when inference is observational or comparative.
